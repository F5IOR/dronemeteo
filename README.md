# 🚁 DroneMétéo

Application météo pour les pilotes de drones.

## 🌐 Accès

**https://f5ior.github.io/dronemeteo/**

## ✨ Fonctionnalités

- 🌤️ Météo réelle (Open-Meteo)
- 📡 Indice KP réel (NOAA)
- 📊 Score de vol 0-100%
- 🔋 Autonomie batterie estimée
- 💧 Risque de condensation
- 🗺️ Carte interactive (IGN + CARTO)
- 🚫 Zones de restrictions (Géoportail)
- 🛩️ Lien vers Airops-SUPUAV
- 📤 Partage des 3 meilleures heures
- 📍 Position personnalisée au clic
- 💾 Sauvegarde des seuils
- 📱 Responsive mobile/tablette/desktop

## 🎯 Utilisation

1. Ouvre l'application : https://f5ior.github.io/dronemeteo/
2. Cherche ta ville (ou utilise ta position GPS)
3. Consulte le score de vol heure par heure
4. Ajuste les seuils selon ton drone
5. Vole en sécurité !

## 🛠️ Technologies

- HTML/CSS/JavaScript (vanilla)
- [Leaflet](https://leafletjs.com/) pour la carte
- [Open-Meteo](https://open-meteo.com/) pour la météo
- [NOAA](https://www.swpc.noaa.gov/) pour le KP
- [Font Awesome](https://fontawesome.com/) pour les icônes
